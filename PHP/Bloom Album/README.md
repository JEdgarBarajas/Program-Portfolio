Instructions for Running Bloom Album.

Bloom Album is a PHP photo gallery and album website meant to run locally on a 
computer. It requires a server to run on and a MySQL account.

I used Xampp to run Bloom Album. Once Xampp is downloaded, place the Bloom Album 
folder inside the htdocs directory. Then using the Xampp control panel, enable 
Apache and MySQL. 

As of the current version Bloom Album also requires a MySQL account with admin
privileges to created to the BloomDB database. Open the db_init.php file in 
your text editor of choice and replace the password and username with the 
MySQL credentials. 

Finally you can start the project at "localhost/Bloom%20Album/index.php" in the
url.

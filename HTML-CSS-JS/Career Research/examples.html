Bad Example: Berkshire Hathaway

Berkshire Hathaway

Berkshire Hathaway is an unappealing website, and for many reasons.

  1. The first reason I find the site unappealing is the minimal styling applied. The website uses white background that is blinding when paired with the blue text. The fonts are also quite small. The highlighted colors also have poor contrast, and very bright.
  2. The other reason aspect I do not like is the poor navigation. There is no navigation bar making flipping through pages entirely relianton back button. Some of the pages do not have landmarks either, making remembering the correct page cumbersome.
  3. The final reason I find the design unappealing is the lack of responsive design. The site uses a lot of tables for its main content. This means the text is ill adjusted for smaller screens. There are no media queries, or viewports. The rigid choice of font size also hurt here. Strangely though, where the footer should be, the text is responsive using "em" instead.

      4. Improvements:

      This site really could use organization with semantic structure elements like a header, footer, and main. That would also make it more accessible to those using a screen reader. The site would also benefit greatly from a less harsh contrast, to make large text stand out more. Adding navigation might be difficult, but having a side drop down menu would help a lot, since the home page is essentially the navigation with the enormous amount of links.

Good Example : Overflow.co

Overflow.co.

I find Overflow.co's design appealing for a number of reasons.

There are many good things to say about the design of Overflow.co Let's start with accessibility.

The website has excellent responsive design. The large horizontal navigation on desktops is converted in drop down box on mobile. The sites font also changes responsively, becoming larger and easier to read.

The contrast too is strong for the most part. The text is a ratio 13.01:1, while also using complimentary orange and purple.

If I had to criticize the website though, it would be its use of Orange. Orange works well for the young entrepenuer vibe the site is going for, but doesn't contrast well against the near white background.

Overall I am a big fan of the site's liquid design, allowing it to convey a lot of information without being overcrowded.

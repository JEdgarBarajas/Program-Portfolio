Accessibility Standards

Minimum Contrast Ratios
WCAG Standards hold contrast ratios for text, requiring a minimum 4.5:1 contrast for normal text, and a 3:1 contrast for large text and Graphics. These requirements were added to make clear readable text for those with visual impairments.
This Website's header boasts a 7.81:1 contrast, meeeting the WCAG AAA requirements. The main body is 17.13:1 also passing for normal text.
Semantic Names
Users with visual impairments may use screen readers or other assistive technology. It is important to distinguish for the page's structure using semantics elements so that the page is properly read.
There are 5 semantics elements on this website: Header, Nav, Main, Section, and Footer. There are also many land marks to help organize the page in importance for users using assissitive technology.
WAI-ARIA Labels
The Web Accessibility Labels are used to help visually impaired users using screen readers identify interactive elements of a webpage. These include setting roles, and properties.
This website uses Aria-Current page in its navigation, helping users identify what page they are on.
